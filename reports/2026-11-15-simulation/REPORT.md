日期：2026-11-15（Asia/Shanghai）。對象：本地 gods-eye-view 0.3.0；Node v24.22.2。

## 結論

此專案可作地理與太空活動的視覺化、歷史資料回放及部分物理推算前端。此次檢查未找到完整的地緣政治因果、國家決策、經濟制裁傳導或多主體博弈模型，因此不能把地圖動畫當成地緣政治預測。「天緣學」在本報告暫指太空環境與軌道活動分析。

## 如何用於仿真

1. 在專案目錄執行 `npm run dev -- --host localhost --port 4173`，開啟 http://localhost:4173。
2. 地理分析：依研究區域疊加邊界、海纜、氣象、災害與其他所需資料，先核對來源時間與涵蓋範圍。這能回答空間關係，不能自行回答政策造成的因果影響。
3. 太空分析：啟用 Satellites，載入軌道要素，選擇衛星並使用時間軸檢視軌道；衛星過境模組可估算升起、最高點、落下與幾何可見性。可見性不等於實際肉眼可見，仍受天氣、亮度及軌道要素品質影響。
4. 歷史重演：來源必須提供 snapshot timeline；只有即時來源的飛機／船舶不會自動產生歷史軌跡。模組會等待快照載入，並拒用過期的異步回答。
5. 情境展示：Director 場景可編排鏡頭與資料。內建尼泊爾洪災是證據與影像重建，其河道推進不是水動力到達時間模型；火箭上升路徑也可能是重建估計。
6. 真正的地緣情境推演需另接模型：明確定義主體、狀態變量、假設、情境分支及不確定性，再把時間化輸出交給此專案呈現，並與歷史資料校驗。

重跑此次數值範例：`node reports/2026-11-15-simulation/simulate.mjs`。
